# ADR-0001：主机同时作为服务器与玩家

- 状态：Accepted（用户已明确角色要求；不代表功能已实现）
- 日期：2026-09-14
- 来源：用户明确“主机要求既可以作为服务器，也可以作为玩家参与”。

## 上下文

本游戏近期联机范围见 [长期目标](../long-term-goals.md)。需要允许创建房间的人正常参与游戏，不要求为每局额外准备一台只运行服务器的电脑。

## 决策

创建房间的主机同时承担服务端职责和本机玩家角色；其他电脑可作为客户端加入。该模式通常称为玩家主机模式（Listen Server）。

本 ADR 确定角色共存，不指定单进程/多进程实现、网络库或传输协议。

## 替代方案与影响

- 仅允许无界面独立服务器：不能单独满足房主同时玩游戏的要求，因此不作为唯一运行模式；是否额外支持仍未决定。
- 纯客户端依赖固定远端服务：不能单独满足本机可作为服务器的要求。
- 本机玩家和远端玩家应遵守一致的游戏规则，具体命令、状态同步及权限边界需后续设计验证。
- 房主退出、存档归属、主机迁移和断线恢复不由本决策隐含确定。

## 规格与验证

尚无实现 change 或验证结果。后续相关 change 应引用本 ADR，并覆盖“主机玩家参与 + 客户端加入同一局”的场景，而不是只有服务端启动成功。
