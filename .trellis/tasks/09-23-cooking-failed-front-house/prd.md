# 失败重开丢掉前厅现场

> 状态：`in_progress`。需求已审过：失败现场不带进新厨房，成功交接仍先洗完正在洗的碗。

## Goal

失败重开后，座位、未满足、营业时钟和上一关的洗碗队列都丢掉。正在询问的顾客不开进新厨房。不写收益。

## Background

09-19 已确认失败现场不进入下一轮，厨房按标准供应重建。成功交接会清空座位并先洗完正在洗的碗。`CreateRetry` 会新建厨房，但同一个 `CookingFrontOfHouse` 还留着上一关的收尾和队列。

## Requirements

- 失败重开被接受后，座位、未满足、营业计数、收尾标记和洗碗队列都清空。
- 正在询问的桌子直接丢掉，不调用 `OpenOrder`。正在洗的碗不洗进新厨房。
- 新厨房的物品保持标准供应。上一关的脏碗不出现。
- 成功交接仍走原来的清空：正在洗的碗先洗完，其余脏碗留在原厨房。
- 不定义失败条件，不写收益。

## Acceptance Criteria

- [ ] 失败清空后无人在座、未满足为空、收尾消失，厨房订单数和干净碗数不变。
- [ ] 宿主失败重开后，下一拍可以再来一位新客人，不是延续上一关收尾。
- [ ] 成功交接的旧行为仍在。
- [ ] 两个既有门禁通过。
