D. 实现合同、派发顺序与必跑验证

结果合同必须先定清楚：

五状态大小写严格匹配：Passed/0、Failed/1、Blocked/2、Skipped/3、NotRun/4。processExitCode 单独保留真实原生值，不能把任意程序的 exit2 直接解释为 Blocked。
缺必需工具或尚未支持的执行合同是 Blocked；已执行失败、损坏/矛盾证据、超时和已启动后的取消是 Failed，附具体 reason。未启动的后续步骤为 NotRun。
N/A 是验收范围说明，不新增第六种执行状态。
每次运行使用唯一 runId，每个节点使用唯一 resultId/调用路径；目录必须全新。不能继续使用“秒级时间+gate 名”作为唯一隔离，也不能让重复 nested gate 共用产物目录。
结果至少包含：schemaVersion、身份/父子关系、kind/status/CLI/原生退出码、reason、源 SHA/dirty/输入指纹、配置 hash、实际命令参数数组、工具身份、调用与执行时间、required/optional/completed/missing、coverage bindings、tests、artifacts、provenance、完整 children、fullGateAccepted。
主控/runner 分配身份和声明，子结果不能自行选择它的信任上下文。叶子不能带 children 或宣布整个 gate 已验收。
completed 只能来自已验证的当前 Passed 叶子；每个 token 必须绑定非空、唯一、可解析的结果 ID。父节点按配置树和叶子重新计算，拒绝空绑定、失配、重复、缺子项和伪造汇总；必须测试 JSON 往返后的对象，不能只验证内存 Hashtable。
required/optional 不重叠；missing 是声明集合减去真实完成集合。所有 Cooking 步骤仍 required，不为变绿改成 optional。
必需 Failed/Blocked 向上传播；聚焦选择导致覆盖不足时，父结果 NotRun/4、fullGateAccepted=false，即使选中叶子 Passed。父调用时间可存在；未启动叶子的命令/执行时间/原生退出码为 null。
可选项只有预先声明的非执行政策可以保留原始原因并记 Skipped；坏证据、真实失败不能借 optional 被洗掉。仅在必需覆盖全部完成时，父 gate 才能通过自身声明。

.NET 与产物身份：

保留并加强现有 TRX 校验。解析实际结果条目、唯一执行身份、测试定义/程序集、summary 与 counters；零实际执行、失败/错误/超时/中止、计数矛盾、错误程序集/filter、旧结果均不能成功。规范化计数使用不重叠分类：total=resultEntries=passed+failed+skipped+notExecuted，executed=passed+failed；原始 TRX 各字段按其真实语义核对，不能机械相加重叠计数。
纯 build 的 tests=null，不虚构测试数。完整测试声明下未执行/跳过的必需测试不能当成覆盖完成；任何例外必须事先明确，不能事后豁免失败。
source 包含精确提交、dirty 明细/指纹及运行前后检查；输入覆盖实际项目引用、Compile Include、导入 props/targets、配置、包解析与生成/分析工具。不能只靠扩展名白名单、mtime 或“SHA 一样”。
记录 restore/build/test 各阶段真实 argv、工具/SDK/宿主版本、开始结束和退出码；保存 assets/依赖解析、项目/TFM/Configuration 与实际测试程序集、相关依赖二进制的 hash。执行前后核对，快照只写进本 run 拥有的证据目录，避免下一步重建覆盖旧证据。
可把 test 适配器拆为有记录的 restore→build→test --no-build --no-restore，让测试消费已核实的二进制；不能把前两段藏成“没有执行”。
NoBuild 保持现有语义：跳过测试隐式构建，不跳过配置里的显式 dotnet-build 步骤。NoBuild/NoRestore 必须分别记录跳过与复用来源，不获得“本次执行过”的信用。
最小复用入口可新增显式 -ReuseManifestPath，指向按项目/TFM/配置索引的既有阶段回执集合；不自动猜最近一次成功目录。NoRestore 只要求有效 restore 证据，不强迫先前 build 也成功；NoBuild 因同时依赖已恢复的构建产物，须两者均有效。缺证明 Blocked，证明损坏/失配 Failed。默认完整验收不使用这些复用开关。
artifact 记录所属 run/result、相对路径、角色、长度/hash；拒绝路径越界、reparse/symlink 逃逸、旧 run 与后来替换的 DLL。原生 stdout/stderr 直接保存，不能经过 PowerShell ErrorRecord 排版再当原文；不宣称合并两条流后的顺序是真实时序。
