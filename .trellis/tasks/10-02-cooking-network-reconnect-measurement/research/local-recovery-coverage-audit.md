## Source-only paths worth retaining

`CookingNetworkSessionHost.InstallCapture` terminalizes `_waiting` as ScopeRetired before clearing mappings/domain/cleanup and resetting Ready/Issued/backpressure on scope change. It does not reset the existing connection sequence there; sequence resets during successful rebind. Therefore a proposed new-scope low-sequence test must distinguish same-connection continuing sequence from NEW-generation sequence reset; do not invent a contract that resets sequence on every scope change.

Host source cancellation separates per-caller history from logical execution terminals. Session maps all-canceled logical identities to CancelledNoExecution; a surviving identity must keep the first batch/fingerprint. These code paths justify targeted regression, not a claim that dropped original command replies have been observed. Fault/bounds latch unavailability, whereas Busy is transient and must never publish a stale healthy baseline to reopen admission.
