# Menu catalog source and mapping contract

S04 source catalog, not a level menu or a second kitchen authority. Production acceptance remains pending core Execution/YieldPortions/multiset/processing-vessel and S05 binding/disposal/identity hooks. Original v0.1 Markdown/Excel are immutable design sources.

- Source IDs plus expected names select explicit stable runtime identities. Row order cannot assign identity. Unknown/missing/duplicate IDs or ambiguous names reject; changes require explicit manifest review.
- Preserve original attachment hashes and all367 node cell/row provenance. Each node maps to shared/expanded recipes or a distinct delivery operation; count equality alone is insufficient.
- Supplies, preparations, intermediate stages and finished products have separate DefinitionIds; recipes/processes/stations/vessels/order templates have separate typed IDs. Ketchup/fresh sauce and instant/fresh tea differ; D28 has no tea.
- Inputs are positive integer portion multisets. Stage expansion must preserve original direct multiset. Independent branches remain independent; stage order is a graph of real output objects, never row ordering or a MustLast label alone.
- Actual thermal carriers persist through load/heat/unload; runtime validates required processing vessel. Serving vessels are distinct. New hot/cold cups are disposable world supply and refill dependencies; plates/bowls use existing wash pool.
- Requirements exposes production versus delivery capability closure and refill containers.31 source station discrepancies preserve missing drink-binding dependency instead of rewriting source or adding fake processing steps.
- Catalog normalization/hash includes source provenance and fixture status. Formal configuration/checkpoint identity must consume catalog/source identity before declaring actual production integration.
- Ticks1/yield2 for selected shared preps/raw8/vessels2/score100 are explicit tests, not balance.87 candidates are not a level assignment.
- Full S09-S13 acceptance requires public-command production/submission and ET checkpoint equivalence per all87 routes; static graph/catalog loads never substitute for those results.
