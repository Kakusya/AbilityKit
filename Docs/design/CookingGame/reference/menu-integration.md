# 87 款候选菜单导入规划

2026-10-02；planning-only。来源见 [menu-v0.1/README.md](menu-v0.1/README.md)。44 正餐 + 12 甜品 + 31 饮品是完整候选范围，不是首关、不按杯型/糖度/冷热变体扩充数量。原文中的来源与“完整依赖闭合”是供稿陈述；本轮只核对目录身份和附件结构，不宣称已通过生产配置校验或重新核实原作机制。

## 现有模型与缺口

现有 `CookingRecipeDefinition` 用 Inputs、ProductDefinition、Process、RequiredApplianceCapability、RequiredTicks、DefaultInputs、Completion、RequiresStation 表达单步加工。已有内容加载、订单模板、标准供应、兼容性、加工锁定、端走继续、两种完成形态、净/脏碗池与提交结算。正式番茄蛋花汤和吐司保留，不和 F04 番茄汤合并。

| 菜单需求 | 当前可复用 | 尚需规划/实现 |
|---|---|---|
| 共享切配/熟制成果与并行分支 | 物品实例、多输入配方、独立加工 | 全链拓扑、材料来源、跨菜共享 ID 和关卡闭合校验 |
| 同材料 ×2 | Inputs 可表达重复投料 | 附件映射后测试计数匹配，不能只看 distinct 集合 |
| 一锅多份、一壶共享 | 容器、Pour 和完成形态 | 明确批量产量、剩余份数、按份转移与守恒；现有 Pour 是整份转移 |
| 加奶油/奶泡/奶盖的阶段顺序 | 多步物品状态可组合 | 阶段先后和后续合法添加，不能让最终无序配方跳过收尾 |
| 手工与设备不同 | StartProcess + 固定 Tick | 手工持续参与、暂停/保留、接手；当前自动进度不算按住操作 |
| 19 功能工位与模式 | capability 匹配 | 搅拌/搅打/榨汁、煎/炸/蒸/烤区分；蒸汽机加热/打泡模式与占用规则 |
| 餐食不贴标、饮品独立贴单 | 配方身份和 OrderId 已分离 | 成品绑定、解绑、换绑、状态投影与交付校验 |
| 限定出餐容器 | 容器定义、兼容性、订单要求 | 盘/碗/热杯/透明杯等显式 ID 与阶段映射；加工容器不直接交付 |

## 内容记录契约（规划）

成品沿用源编号 F01–F44/S01–S12/D01–D31；这些是设计编号，不直接充当生产 DefinitionId。后续建立映射表，分别列供货物料、准备状态、成品、工序、工位、容器、订单模板，不能一个名称混用多个身份。

每条候选需记录：来源编号/名称、投入与游戏份数、依赖准备状态、独立分支、阶段先后、能力/模式、加工容器、出餐容器、完成形态、批量输出、订单绑定策略、关卡许可、拟映射 ID、校验与状态。无批准的数值标为待平衡；fixture 值与正式值分栏。

供应番茄酱与现制番茄热酱分开；粉冲奶茶与现泡奶茶分开；黑糖珍珠鲜奶不含茶；熟珍珠需制作，椰果/仙草直接供应。默认不增加洗菜、削皮、去核、去骨、盐油巡检、精准刀工、拉花、冷却融化计时或每杯封盖动作。

## 内容增量顺序

先补共同规则，再分批导入。每批覆盖完整供应→共享准备→成品→容器→订单→清理恢复；不为单菜写专用拿放系统。

| 批次 | 候选编号 | 覆盖重点 | 前置 |
|---|---|---|---|
| M1 正餐与基础组装 | F01–F16、F21–F27、F43–F44 | 切配、煮、煎、并行汇合、按份盛装 | 单机空间/加工/批量/拓扑规则 |
| M2 更多热加工 | F17–F20、F28–F42 | 未熟半成品交接、烤/蒸/炸/串、锅与出餐小锅 | M1 与设备能力扩展 |
| M3 甜品 | S01–S12 | 共享面糊、奶油、模具、混合后分流 | 批量、阶段顺序、模式区分 |
| M4 冷饮与冲调 | D01–D14 | 果汁壶、榨汁/搅打、冷热杯、独立贴单 | 批量与票据规则 |
| M5 咖啡与茶 | D15–D31 | 研磨/萃取、蒸汽模式、茶桶、小料、最后加奶盖 | M4、阶段先后、设备模式 |

M1 并非首关菜单；首个验证组合建议 F01/F11/F21，随后扩本批。D01/D04/D25/D31 用于验证直接供应、共享基底、小料和必须最后收尾。它们不缩减完整 87 款候选目录。正式时间、数量、价格、关卡分配不在本轮定死。

## 以后必须实际验证

- 87 个成品编号唯一且完整，44/12/31 分类相符；Markdown 与 Excel 不一致时保留差异，不猜覆盖。
- 每个投入有供应来源或制备路线；图无环，重复份数正确；本关所有依赖/设备/容器可用。
- 批次份数守恒；混合/分装不复制物品；两次同命令、同时取最后一份只有一次成功。
- 独立分支允许任意合法先后；必须最后的奶泡/奶盖不能提前；切换设备模式不偷跑进度。
- 容器兼容、内容锁定、移动/交接、订单绑定、错误清空均能恢复；拒绝没有部分扣料。
- 导入不改变现有汤/吐司回归；ET 同 Level checkpoint 重建后的终态与不中断基线一致。
