# Cooking 正式菜品与加工过程候选目录 v0.1

日期：2026-10-02。状态：planning / 建议稿，未逐项批准。

本方案以《胡闹厨房 2》及其 DLC 的加工品类、《杯杯倒满》的饮品结构为参考，重新设计为同一套餐厅内容。不是原作全配方逐条复刻，也不是首关或 MVP 菜单。

**87 款成品：44 正餐、12 甜品、31 饮品；26 个品系；72 项供应原料；60 项准备状态；19 种功能工位（含贴单）。**

## 四、供应原料

以下为供货或直接取用边界；不将原料展开至农业、制粉、制糖、乳制品生产等更上游过程。

生菜、番茄、黄瓜、洋葱、蘑菇、胡萝卜、土豆、西兰花。

### 水果

橙子、柠檬、苹果、香蕉、草莓、芒果。

### 肉蛋海鲜

生牛肉饼、牛肉块、牛肉末、鸡肉块、生鸡排、三文鱼肉、白身鱼肉、虾仁、生香肠、培根、鸡蛋、意式腊肠片。

牛奶、淡奶油、芝士片、软芝士、酸奶、香草冰淇淋、椰奶。

### 谷物与预制主料

米、干意面、汉堡面包、热狗面包、吐司片、卷饼皮、饺子皮、披萨面团、甜点预拌粉、生甜甜圈坯、派皮、饼干片、海苔、生薯条、炸粉。

### 咸味基础

清汤底、番茄酱、芥末酱。

### 甜味配料

糖浆、黑糖浆、蜂蜜、可可粉、巧克力酱、草莓酱、棉花糖、巧克力块。

### 茶咖啡与冲调原料

红茶叶、绿茶叶、乌龙茶叶、咖啡豆、速溶奶茶粉、抹茶粉。

### 饮品小料

生珍珠、椰果、仙草冻。

### 饮用液体与冰

饮用水、冰块、可乐原液、苏打水原液。

## 五、工位目录

| 工位 | 能力 | 操作边界 |
|---|---|---|
| 切配台 | 切配蔬果、肉鱼；处理一份原料 | 统一交互；没有刀数、轨迹、去皮清洗小游戏。 |
| 组装台 | 装配、裹粉、卷合、包制、整份摆盘 | 一份一个操作结果；不逐个饺子捏褶、不逐层微调坐标。 |
| 煮锅 | 煮饭、煮面、熬汤、炖煮、煮珍珠 | 各任务独占一只锅；水油盐为设备/基础配方抽象，不逐次搬水加油。 |
| 煎台 | 煎肉、煎蛋、煎松饼、炒/熬酱 | 投料后计时，玩家可离开；不增加翻面时机小游戏。 |
| 烤箱 | 烤披萨、蛋糕、果派、拼盘、吐司 | 烤盘或模具进出；不模拟预热、发酵、复杂冷却。 |
| 蒸锅 | 蒸饺、蒸鱼 | 已组合半成品进入加工；不单独补水。 |
| 炸锅 | 炸薯条、鸡块、鸡排、鱼排、甜甜圈 | 油为设备背景条件；取放与完成状态清楚。 |
| 烤架 | 烤串、烤棉花糖 | 串制/夹心组装由玩家完成；不添柴、不逐面旋转。 |
| 搅拌机 | 制作甜面糊、打发奶油、奶盖 | 同一简单启动操作；产物由投入材料决定。 |
| 榨汁机 | 水果/蔬菜切配件榨取 | 先切配后投料；不精确控制压榨力。 |
| 搅打机 | 奶昔、冰沙、果泥 | 投料—加工—倒出；无按键节奏。 |
| 调饮台 | 定份混合、冲调、按序加料 | 一份一次；不精确控制毫升和搅拌圈数。 |
| 泡茶桶 | 茶叶加热水制茶底 | 茶底可提前做；每桶产出份数作为后续数值项。 |
| 磨豆机 | 咖啡豆制咖啡粉 | 一次简单加工；无研磨刻度选择。 |
| 咖啡机 | 咖啡粉萃取浓缩 | 不独立模拟布粉、压粉、清洁把手。 |
| 蒸汽机 | 加热牛奶/饮品；牛奶打泡 | 加热与打泡是两种明确模式；没有温度瞄准、拉花。 |
| 取水台 | 取饮用水、热水 | 饮品配方中的水显式存在；烹饪设备用水不逐份操作。 |
| 汽水机 | 取可乐、苏打水 | 需要供应的饮料液；不是无限凭空生成。 |
| 贴单台 | 完成饮品后绑定订单 | 不属于配方成分；不对所有餐食附加同样的手续。 |
